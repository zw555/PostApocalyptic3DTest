# After Hours · Stage 6-B.5-B2 追击目标保持

开发与自动验证已完成。进入 C.1 前，玩家决定暂时接受当前追击表现并继续开发。追击手感改善有限，仍是待优化问题。

## 根因

B.5-B1 只在 `CHASE` 和 `ATTACK` 中启用对已发现目标的全向追踪。攻击结束后的感知采样遇到实体遮挡，或追击中的目标超过 6 m 达到原有丢失宽限时，AI 会进入 `INVESTIGATE`。该状态仍保存最后目击坐标，旧实现却停止全向追踪。玩家在调查期间回到背后 6 m 内时，即使射线已通、导航路径有效且仍在五楼走廊，也要重新进入正面视锥。持续通视的绕背对照中，旧实现已能继续追击。

修复在 B.5-B1 的僵尸适配脚本中保存已确认目标。正式视觉确认或合法受击会使 AI 进入追击或攻击并建立确认。进入调查时保留已有确认，单靠贴身触发调查不会建立确认。调查期间恢复实体通视且仍在 6 m 内时，使用原来的视觉确认时间恢复追击。遮挡期间继续使用最后可见位置。返回、待机和死亡会清除确认。进入 501 或楼梯仍按原有边界检查当帧取消攻击并清除目标。首次视觉发现仍为 6 m、120° 和 0.20 s。

## Vulkan 状态轨迹

Godot 4.5.2，Vulkan 1.3.289 Forward+，RTX 4060 Laptop GPU。四组路线均在现有住宅楼的同一段走廊，玩家以原有 CharacterBody3D 移动，往返端点为 X −5.19、Z 1.90 和 5.50，窗口约 5.52 s。正面和背面组沿同一路段反向行走。遮挡组使用测试场景运行时插入的物理挡板，移除时核对视线、夹角和导航路径。超距用例用同一合法走廊的两个起点复现 6 m 边界。

| 走廊场景 | CHASE 时长，前 → 后 | ATTACK 时长，前 → 后 | 进入调查，前 → 后 | 进入返回，前 → 后 |
| --- | ---: | ---: | ---: | ---: |
| 正面持续通视 | 2.10 → 2.10 s | 3.43 → 3.43 s | 0 → 0 | 0 → 0 |
| 攻击期间绕背，持续通视 | 1.05 → 1.05 s | 4.48 → 4.48 s | 0 → 0 | 0 → 0 |
| 正面短暂遮挡 | 1.75 → 1.75 s | 3.00 → 3.00 s | 1 → 1 | 0 → 0 |
| 攻击期间绕背，短暂遮挡 | 0.47 → 1.17 s | 0.78 → 3.58 s | 1 → 1 | 1 → 0 |

- **攻击后绕背。** 0.967 s 因射线遮挡从 `ATTACK` 进入 `INVESTIGATE`，旧版在此失去全向追踪。1.600 s 恢复视线时，距离 3.11 m、夹角 163°，导航路径有效。旧版到 5.050 s 进入返回，直到 5.283 s 玩家重新进入正面视锥才开始追击。修复版在 1.783 s、夹角仍为 113° 时恢复追击。
- **超距后从背面接近。** 超过 6 m 后停止更新目标位置，0.650 s 进入调查。0.683 s 回到距离 4.36 m、夹角 180°、射线通畅的位置。旧版在随后 0.75 s 的观察窗口内没有恢复追击，修复版在约 0.20 s 后恢复。
- **背后受击。** 真实鼠标刺击结算一次，僵尸从待机进入追击，确认状态通过原有硬直保留，随后转身、追击并按旧前摇和冷却开始反击。
- **撤退和死亡。** 两个真实开门门槛都通过物理跨越验证。边界在当帧清除确认并取消待结算攻击，玩家没有事后扣血。僵尸死亡后清除确认并停止追击。
