# Stage Item-Art A1：短刀刀根局部修复

日期：2026-11-17。状态：**等待玩家人工验收**。

## 诊断与处理

原刀根的主斜面从未开刃段向研磨面过渡时，四角高度不同，并非共面四边形。原生成器只沿一条对角线拆成两个三角形，同时逐三角面赋平面法线，造成明显的三角形明暗分割。原始坐标解析得到最严重四边形第四角偏离前三角平面约 0.81 mm；加载保存后的 Mesh 实测，对角两个三角形最大夹角约 15.43°。

先试验仅修复法线：视觉有所改善，但原有粗三角面仍无法充分表达过渡曲面，因此进一步进行局部拓扑修复。

- 仅对距刀身后端 6.375～19.125 mm 的主斜面条带细分，共上下两面各四个原四边形。每个四边形采样为 8×8 双线性曲面网格。
- 保留原四角和四条边界。新顶点位于原四边形的双线性曲面上，改变其内部三角面插值，消除单条大对角线造成的突变。
- 主斜面采用角度加权的共享顶点法线，上下两面分开计算。斜面与刀身主体、刃口之间仍保持独立硬边，不把真实研磨结构抹平。
- Drop Point 刀尖、刀腹曲线、原始研磨肩线坐标、刃口、刀背、厚度均保留。肩线原先随刀宽变化的轻微连续曲率没有强行拉直；修复针对根部内部折面与法线造成的异常弯曲观感。
- 未增加磨损、贴图或任何用于遮盖问题的材质变化。

局部小四边形的对角三角面最大夹角降至 **2.00°**。整刀三角面由 4,172 增至 5,180（增加 1,008）；仍为 8 个 Mesh、9 个材质。尺寸不变：全长 286 mm、最大宽 47.6 mm、总厚 21.6 mm；刀根钢材厚度 4.4 mm。

## 人工验收

继续双击当前目录的 `RunPreview.bat`，或在 Godot 中运行 `preview/knife_preview.tscn`。

1. F1/F2/F3/F4 分别查看 45°、65°、85°、12°，滚轮放大刀根。
2. 左键拖拽或 A/D 旋转；按 F 翻面，检查上下斜面。
3. 按 L 切换游戏近似光与辅助检查光，观察高光扫过刀根时是否仍有不规则三角折面。
4. 确认主体与斜面分界没有异常折线，刀尖、刀腹、钢材厚度及刀柄/护手仍符合原设计。

当前证据显示根部明显三角明暗裂片已消退，但程序化曲面仍为有限细分三角网格；极端放大下边缘分段、根部曲率及高光连续性是否达到美术标准，需要玩家在 Godot 中旋转确认。没有将自动检查通过等同于视觉验收通过，也未做性能通过声明。
